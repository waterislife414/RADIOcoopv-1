# Radio Co-op Taxi: what every worker must know (read fully before any edit)
Business: radio-dispatched taxi co-op, Columbus GA / Phenix City AL. Owner Jared; operator Malcolm; dispatcher is the manager of all drivers (can change any driver's status at any time). App rides run rider<->driver; phone/cash/guest rides go by radio.
Stack: React 19 + Vite + Tailwind (plain JS/JSX), Firebase Auth/Firestore/Functions v2 (CJS in functions/), Stripe, Twilio. NOT Supabase/TypeScript/pnpm. Security is firestore.rules (no RLS). Config lives in branding.config.json.
Data map (verified in code): users/{uid} = rider/driver profile incl. phone, photoUrl, idVerified (admin or owner reads). drivers/{uid} = warnings, agreement{version,docs}. support_tickets, approval_requests, owner_inbox, mail_queue are written only by Cloud Functions. Clients never write board/offers/ledger/wallet/payments.
Driver screen: src/components/driver/DriverStatusPanel.jsx. Check Ready errors arrive as HttpsError details e.g. {agreement:true},{weakGps:true,accuracy}, {inspection}. GPS: src/hooks/useDriverGps.js exports MAX_ACCURACY_M (100 m, from branding.config.json dispatch.gps.maxAccuracyMeters).
Admin: src/components/admin/Pegboard.jsx (dispatcher board), ApprovalPopup.jsx, CarActionsModal.jsx; status colors in src/utils/statusColors.js (Ready green, On a call orange, Moving blue, Out red; colour always paired with a word).
Test ids you can rely on: pegboard, pegboard-map, status-key, new-call, working, off-out, needs-dispatcher, zone-strip, gps-accuracy, ready-blocker, ask-dispatch, approval-answer, call-drawer, demo-clock, demo-location.
Demo: `npm run build:demo` -> dist-demo; sessions via ?as=guest|demo-rider|demo-driver-44|demo-driver-12|demo-admin|demo-mechanic. QA scripts in tests/qa (Playwright, QA_BASE env).
Routes: /driver-agreement exists. Config values go in branding.config.json; no hard-coded names, phones, prices, colours.
QA: tests/qa/step1.py (193 lines, full step 1 click-through) and tests/qa/common.py (helpers: BASE, check, report, watch, db, accept_gate) already exist; serve with `node tests/qa/serve.cjs dist-demo 8790`. The qa workflow runs it (push branch qa-run/x).
